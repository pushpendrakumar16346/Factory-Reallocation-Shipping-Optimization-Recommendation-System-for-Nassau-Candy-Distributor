NASSAU CANDY DISTRIBUTOR - DATA ANALYTICS PROJECT

PROJECT OBJECTIVE:
Analyze sales, profit, products, customers, regions, shipping,
factory allocation, logistics and business performance.

DATASET:
Nassau Candy Distributor.csv

DATA PROTECTION RULES:
1. Original CSV must never be modified.
2. Original rows must remain unchanged.
3. Original date values must remain unchanged.
4. All transformations must use separate working copies.
5. Processed datasets must be saved in data/processed.
6. Original CSV must never be overwritten.

data/raw

REPRODUCIBILITY:
